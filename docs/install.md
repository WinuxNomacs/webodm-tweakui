# Install

## Requirements

WebODM 3.3.2 or later (tested on 3.3.2 and 4.0.0).

## Installing

In WebODM, Administration > Plugins: install TweakUI from the plugin directory, or upload the latest release's
`tweakui-<version>.zip` from the repository's [releases](https://github.com/WinuxNomacs/webodm-tweakui/releases).

Then each user opens the **TweakUI** item near the bottom of the side menu, just above About, and turns on the
features they want. An administrator can turn the whole plugin off at any time in Administration > Plugins.

## Outside services

None: the plugin calls no outside service. It keeps each user's settings and themes in the plugin's per-user data
store in WebODM's database, and the published themes in its global data store.
