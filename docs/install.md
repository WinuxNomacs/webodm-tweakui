# Install

## Requirements

WebODM 3.3.2 or later (tested on 3.3.2 and 4.0.0).

## Installing

Once released: in WebODM, Administration > Plugins, install TweakUI from the plugin directory, or upload
`tweakui-X.Y.Z.zip` from the repository's [releases](https://github.com/WinuxNomacs/webodm-tweakui/releases).

Then each user opens the **TweakUI** item near the bottom of the side menu, just above About, and turns on the
features they want. An administrator can turn the whole plugin off at any time in Administration > Plugins.

## Outside services

None: the plugin calls no outside service. It keeps each user's settings, including their theme, in WebODM's
database, in the plugin's per-user data store.
